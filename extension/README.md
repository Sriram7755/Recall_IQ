# CodeRecall

CodeRecall is a Chrome Extension that helps you automatically save and organize your solved coding problems from LeetCode directly to your GitHub repository — keeping your DSA journey tracked and accessible anytime.

---

## 📥 Download Extension

1. Open the Google Drive download link shared with you.
2. Click **Download** in the top-right corner.
3. Save the `.zip` file to your computer.
4. Right-click the `.zip` file and select **Extract All** (or use any extraction tool) to unzip it into a folder.

---

## 🔧 Install and Activate in Chrome

1. Open **Google Chrome**.
2. Type `chrome://extensions/` in the address bar and press **Enter**.
3. Toggle **Developer Mode** on from the top-right corner.
4. Click **Load unpacked** in the top-left corner.
5. Select the extracted **CodeRecall** folder that contains the `manifest.json` file.
6. Wait a moment for Chrome to load the extension.
7. Verify that **CodeRecall** appears in your Extensions list.
8. Click the 🧩 puzzle-piece icon in the Chrome toolbar.
9. Click the 📌 pin icon next to **CodeRecall** for quick access.

---

## 🚀 Usage

- Click the **CodeRecall** icon in your Chrome toolbar to open the extension.
- **Sign in with GitHub** if prompted to connect your account.
- Solve a problem on LeetCode — CodeRecall will automatically detect and save your accepted solution.
- Open the extension anytime to view your saved solutions, topics, and stats.

---

## 🛠️ Troubleshooting

| Issue | Fix |
|---|---|
| **"Manifest file is missing."** | Make sure you selected the correct folder containing `manifest.json`, not a parent or nested folder. |
| **"Extension failed to load."** | Re-extract the ZIP file and try loading the folder again. Ensure no files are missing. |
| **"Developer Mode not enabled."** | Go to `chrome://extensions/` and toggle **Developer Mode** on from the top-right corner. |
| **"Chrome blocked the extension."** | Click **Details** on the extension card and ensure it is enabled. If blocked by policy, check your Chrome settings. |
