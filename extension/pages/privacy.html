Privacy Policy

Effective Date: July 12, 2026 • Powered by Sriii Technologies

At Sriii Technologies, we value the trust you place in RecallIQ. This Privacy Policy details how we collect, use, and secure your information when you use our Chrome Extension and associated backend services.

1. Information We Collect

  • GitHub User Profile: When you authenticate via GitHub OAuth, we request and retrieve basic profile information (GitHub ID, username, email, and avatar URL) to construct your user account.
  • GitHub Access Tokens: We request OAuth permissions to commit code to your public/private repositories on your behalf. These tokens are encrypted at rest using AES-256-GCM and are never exposed in plain text.
  • Submission Metadata: We save problem IDs, titles, difficulties, languages, and solution code blocks from LeetCode to display your stats in the dashboard and push them to your repository.

2. How We Use Your Data

  • To authorize commits and upload solution files directly to your configured GitHub repositories.
  • To compile and represent your coding dashboard statistics (total solved, topic breakdowns) in the extension popup.
  • We do not share, sell, or distribute your private profile information, tokens, or solution histories to any third parties.

3. Data Storage & Security

All database instances are hosted securely in serverless cluster groups on MongoDB Atlas. Communication between the Chrome Extension, the backend server, and GitHub APIs is conducted exclusively over encrypted TLS/HTTPS channels. Tokens are encrypted locally before writes using cryptographic GCM parameters.

4. User Rights & Data Deletion

You can revoke repository permissions at any time directly through your GitHub settings (Applications page). If you choose to delete your account or wipe your token, you can click "Logout" in the extension popup or request complete data removal by contacting us.
